# Contributing

## Run locally

```bash
python3 app.py
```

Open the printed `http://127.0.0.1:…/` URL. Python 3.10+, no pip install.

## Pull requests

- Do **not** commit Instagram exports, ZIPs, `.cache/`, or personal follower lists.
- Do **not** add bulk-scrape, login, cookie, or unofficial private-API features — those PRs will be rejected.
- Keep the app localhost-only and stdlib Python.
- Prefer small, focused changes with a short description of why.
